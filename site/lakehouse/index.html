Reality Checks — 45th Parallel

SnowFigure 60–70+ psf ground snow up there. A-frames shed to the two long sides, so decks, walks, garage doors, and the pool all stay at the gable ends — all three partis are drawn that way on purpose.
Pool structureA 20-ft container pool runs ≈45–50k lb full. It never bears on deck framing — own helical piles or piers with a flush-deck surround. Insulate the shell + heat pump for a May–Oct season; drain-down protocol after.
Site / zoningInland-lake setbacks are commonly 40–75 ft from the OHWM and township-specific; pools usually count as structures. Frost footings 42–60 in. Septic and well drive siting as much as the view does — get them on the plan first.
Garage underDwelling separation per MRC R302.6 at the garage lid and shared walls. Cheap now, annoying in a retrofit.

The Printed Piece — Three Buildable Routes

Route A3DCP plinth / site walls. Printed concrete, on-site or precast. Citizen Robotics in Detroit is the obvious first call. Best fit: SK-1.
Route BPrinted molds → GFRC panels. Print the formwork, cast glass-fiber-reinforced concrete. The most freeze-thaw-proven way to get curved facade panels. Best fit: SK-2 / SK-3.
Route CLFAM polymer rainscreen. Large-format printed panels hung on conventional framing. Lightest and fastest to iterate; verify UV and thermal-cycling specs for a four-season lakefront.

Path to Revit

  1. Drop the actual parcel into Forma — massing, sun, wind/snow, and view corridors on the real lot before committing to a parti.
  2. Winning parti → Revit conceptual mass; generate walls, floors, and roofs by face.
  3. Model the printed element as an adaptive component (or Dynamo-driven surface) so the fab geometry stays parametric while the rest of the model is ordinary Revit.
  4. Export the printed element as STEP/OBJ straight to the fab partner; everything else stays native RVT.
