# Lakehouse Planning Portal

Single-file public portal for a personal northern-Michigan lake cabin project.
Project source, deck, and phase plan live in `../../lakehouse/` (self-contained;
planned to migrate to its own repo later).

Sheets:
- **SK Set** — three A-frame hybrid concept partis (SK-1 Stacked Chalet,
  SK-2 A + Bar, SK-3 Kicked Ridge) as inline-SVG drafting sheets, plus
  45th-parallel reality checks, 3D-printed-element fabrication routes, and the
  path to Revit.
- **Lot Radar** — placeholder. Weekly lakefront-lot discovery + SK-fit scoring
  dashboard lands here at its Phase 3 (see `lakehouse/CLAUDE.md`).

- One `index.html`, no build step, served via GitHub Pages at
  `/hw-price-radar/lakehouse/`
- Google Fonts from CDN only — page fully renders without it
- Concept only, not for construction; no parcel, budget, or listing data
